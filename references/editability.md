# 对象计划与编辑能力

按本次需求确定能力，默认轻量混合结构，具体素材及性能处理见lightweight.md。

| 对象 | 默认实现 | 声明能力 |
|---|---|---|
| 正文、普通标题与标签 | 原生文本，保留重点词分色与换行 | 直接改字 |
| 数据、表格、数据图表 | 原生对象，保留数据与标签 | 改数据、改样式 |
| 关键流程框、编号、独立箭头 | 少量原生对象 | 移位、改色；含字节点可改字 |
| 复杂笔触标题、图标、插画 | 独立图片 | 移动、缩放、替换 |
| 照片、真实Logo、科学影像、截图 | 独立来源图片 | 移动、缩放、替换 |
| 无内容场景、纹理与装饰 | 独立或合并图片 | 替换、调整位置 |

用户要求全部原生或标题直接改字时，优先满足指定能力。原生字形轮廓可改形状和颜色，不等于直接改字；细节见fidelity.md。

每对象记录ID、页码、bbox、准确内容、期望能力、预期与实际类型、实现方式、字体字号字重、颜色、行距、对齐、换行、层级和素材。复杂表格或流程拆到可操作子对象，底色与装饰也纳入计划。

所有正文、表格和整组流程不能用图片替代。图片不带相邻正文，不藏旧字、旧框或重复图标；移开模块后不能露出旧残影。

核对计划与实际导出对象。在副本实测代表性改字、改数据、移位、改色、图片替换和组内编辑。只验证对象数量不足以证明能力；导出后的名称、坐标和层级也须核实。未达到用户指定能力时查证修复并披露限制。
